# 随影 ShadeBar v1.5.2

本次是缺陷修复版本（PATCH）：解决**开机后整条着色链路失效**（时间、日期、托盘、
指示条一起不着色，软件仍在运行）。功能与设置项与 v1.5.1 完全一致。

## 修复

- **冷启动后时间 / 日期 / 托盘 / 指示条全部不再着色**：v1.5.1 在任务栏构建期自动
  重放（`Unadvise + Advise`），第二次 `Advise` 返回 `E_UNEXPECTED(0x8000FFFF)`。
  如果重放先退订，唯一有效的订阅就被拆掉，整条链路立即失效；再重建诊断会话也
  无法恢复（拿到的是同一条已失效的连接）。
- **v1.5.2 起彻底移除自动重放**：只建立一次订阅，完全依赖 XAML 的 `Add/Remove`
  增量事件。实测保持订阅时，新打开的应用窗口会正常送来 `Add`，指示条立即着色
  （打开计算器后指示条 4 → 5），不需要也不应该重放。
- 同时移除会话重建、启动预热与重放退避；`Add` 诊断日志预算 60 → 200，
  便于观察新窗口元素。

## 验证

- explorer 重启真机：`check_payload_sync.py` C1–C7 全 PASS，`[Replay]` 0 次；
  新打开计算器后指示条即时增加并着色。
- 单元测试 232 项通过（app 133 / core 97 / doc 2）。
- 打包五道门禁全绿（体积 / 无 VC++ 运行时 / 版本资源 / 清单 / 图标）。

## 兼容性与已知限制

- 已在 Windows 11 26H2 Build 26300.9711 实测；Windows 10 未验证。
- 单文件 exe，**无需 VC++ 运行库**；普通用户权限，全生命周期 **UAC = 0**。
- 升级后若颜色行为异常，请重启资源管理器（explorer）或重启电脑，让 explorer 加载新载荷。
- 图片型托盘图标（第三方应用自绘位图）仍无法染色；多显示器仍只处理含任务栏的主屏。

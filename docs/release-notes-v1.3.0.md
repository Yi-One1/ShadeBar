# 随影 ShadeBar v1.3.0

设置窗口整体重做：四页签、任务栏直控预览，并修复一批对齐、范围与反馈问题。

## 亮点

- **四页签设置窗口**（720×560）：任务栏 / 采样 / 托盘 / 诊断，去掉了左侧导航与
  「基础 / 高级」分档，一屏就能看完。
- **任务栏直控**：任务栏页用一块实时预览直接操作 **图标 → 托盘 → 时钟** 三区开关、
  亮端 / 暗端色与亮度阈值，页面本身就是说明。
- **底栏动作**：恢复默认（二次确认）、导入配置、导出配置、关于。
- 可见设置收敛为 **20 项**（39 项编号与 `config.json` 下标保持不变，旧配置原样读回）。

## 修复

- 控件文字按实际字号量宽并居中，修复「恢复默…」「暂…」等截断。
- 托盘溢出箭头 `^` 改为矢量线段绘制，位于托盘组最左、与图标垂直居中，
  分界线上不再有内容。
- 预览跟随端色：亮端用浅色条 + 深色字，暗端 / 暂停 / 降级保持深色条。
- 采样带改为同款迷你任务栏并垂直居中，采样区外遮回壁纸色。
- 数值范围与实际一致：阈值刻度 **0.30–0.70**；图标区采样宽度 **10–84%**
  （上限为托盘区起点），旧配置中的 100 会自动收口到 84。
- 导出诊断包给出反馈：成功提示完整路径，失败提示检查数据目录权限。

## 下载与使用

- 附件：`随影ShadeBar_v1.3.0.exe`（单文件，免安装）。
- 双击运行，右键托盘图标可打开设置 / 暂停 / 开机自启 / 导出诊断包。
- 配置与数据目录：`%LOCALAPPDATA%\ShadeBar\`；诊断包在 `diagnostics\` 子目录。
- 建议与 TranslucentTB 搭配使用；不修改系统主题、不改壁纸、不重启资源管理器。

## 环境与限制

- Windows 11 26H2（Build 26300）真机验证；更早版本未承诺。
- 托盘字形图标可着色；微信、QQ 等程序自绘位图图标保持原样。
- 悬停高亮块尚未验证，未开放设置。

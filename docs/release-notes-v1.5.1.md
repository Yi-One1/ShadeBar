# 随影 ShadeBar v1.5.1

本次是缺陷修复版本（PATCH）：解决**开机后任务栏左侧图标指示条不着色**。功能与设置项
与 v1.5.0 完全一致。

## 修复

- **开机后正常态指示条不随任务栏背景变色**：开机自启时载荷注入早于任务栏 XAML 建完，
  首次订阅只拿到时间 / 日期 / 托盘 8 个元素；首拍发现指示条 0 命中后立即重放
  （`Unadvise + Advise`），此时树仍在构建，`Advise` 返回 `E_UNEXPECTED(0x8000FFFF)`，
  订阅永久失效。之后开机才启动的应用，其指示条再也进不了元素表，只有重启 explorer
  才能恢复。
- 修复后：订阅后**预热 10 s**、树静止 2 s 才允许自动重放；失败按 **2/5/10/30 s** 退避；
  连续失败 **3 次**自动释放并重建诊断会话，无需手动重启资源管理器。
- 载荷日志增加 `[HH:MM:SS.mmm]` 时间戳，便于开机故障排查。

## 验证

- explorer 重启真机：15/15 拍写入指示条；`tools/check_payload_sync.py` C1–C8 全 PASS。
- 单元测试 232 项通过（app 133 / core 97 / doc 2）。
- 打包五道门禁全绿（体积 / 无 VC++ 运行时 / 版本资源 / 清单 / 图标）。

## 兼容性与已知限制

- 已在 Windows 11 26H2 Build 26300.9711 实测；Windows 10 未验证。
- 单文件 exe，**无需 VC++ 运行库**；普通用户权限，全生命周期 **UAC = 0**。
- 升级后若颜色行为异常，请重启资源管理器（explorer）或重启电脑，让 explorer 加载新载荷。
- 图片型托盘图标（第三方应用自绘位图）仍无法染色；多显示器仍只处理含任务栏的主屏。

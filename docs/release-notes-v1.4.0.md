# 随影 ShadeBar v1.4.0

本次是功能版本（MINOR）：新增**分区独立配色**、**指示条不透明度**与**左键双击托盘图标**，
并修复托盘字形与指示条选中态两处真机缺陷。

## 新增

- **分区独立配色（S-52 ~ S-59）**：正常态指示条、选中态指示条、托盘区字形、时间与日期
  四类内容，可各自配置「背景偏暗」「背景偏亮」两种颜色。任务栏设置页以 2×4 色块矩阵
  直接取色；偏暗行给浅色板、偏亮行给深色板，也支持 HEX 与系统调色板。
- **正常态指示条不透明度（S-60）**：0–100%，默认 45%；统一与分区两种判定模式都生效。
- **左键双击托盘图标（S-51）**：动作选项与左键单击一致（打开设置 / 打开托盘菜单 / 无操作），
  默认「无操作」。双击动作非无操作时，单击会等待系统双击窗口，双击命中则取消挂起的单击。

## 改进

- 托盘右键菜单收敛为 **4 项**：打开设置 / 开机自启动 / 版本号（灰显只读）/ 退出。
- 「采样带垂直内缩」改为按**任务栏高度百分比**生效，预览上下对称内缩，读数单位由 px 改为 %。
- 「亮度阈值」「指示条不透明度」与采样页 5 条滑轨统一为 10 dip 圆角轨道 + 12×14 药丸滑块。
- 设置编号 39 → 49，可见设置 20 → 30 项；旧 `config.json` 自动补齐默认值，原设置不丢。

## 修复

- **托盘图标不改色**：载荷此前按类型 `AdaptiveTextBlock` 匹配，写到的三层里只有 `Base` 的
  `InnerTextBlock` 是可见字形。现按「父级名为 `Base` 的 `InnerTextBlock`」收集并同步还原。
- **指示条两态无法不同色**：载荷选中态误用了正常态颜色，现改读独立的选中态颜色。
- **阈值滑条左端两个黑角**：方形色段盖住了圆角描边，改为中段渐变 + 两端圆帽。
- **统一模式下不透明度滑条拖不动**：命中检测误放在分区模式分支内，已移出。

## 兼容性与已知限制

- 已在 Windows 11 26H2 Build 26300.9711 实测；Windows 10 未验证。
- 单文件 exe，**无需 VC++ 运行库**；普通用户权限，全生命周期 **UAC = 0**。
- 图片型托盘图标（输入法「中」、QQ 等第三方应用自绘图标）仍是位图，无法染色；
  系统文字字形与隐藏图标箭头可着色。
- 多显示器仍只处理含任务栏的主屏。

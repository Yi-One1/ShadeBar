# 随影 ShadeBar v1.3.2

修一个"看不见"的缺陷：**软件在运行，托盘里却没有图标**——只能重启软件才能找回。

## 修复

- **资源管理器重启后托盘图标永久消失。**
  托盘图标是挂在 explorer 上的，资源管理器一重启就被清空。其它程序收到系统广播
  `TaskbarCreated` 会重新挂上，随影从未处理这条广播，于是进程还在、图标没了，
  隐藏区里也找不到（因为根本没在系统里注册）。现在会响应广播并重新对齐图标：
  先按"图标仍在"发 `NIM_MODIFY` 探测，失败才当丢失重挂 `NIM_ADD`。
- **补挂状态机不会自愈。**
  `refresh` 失败时 `added` 从不清零，心跳里的 `first = !is_added()` 永远为假；
  再加上"已挂载 + 外观没变就 return"的短路，图标丢失后既不发 `NIM_ADD` 也不发
  `NIM_MODIFY`，永久静默。现在失败即归零并清缓存键，短路条件收敛为纯函数
  `needs_shell_call(first, added, look_unchanged)` 并加单测锁住。
- **托盘失败原因可见。** 新增 `tray NIM_ADD failed: err=<code>` 日志（每进程最多 3 行）。
  实测重复 `NIM_ADD` 会拿到 `E_FAIL 0x80004005`——正是"直接重挂"写法会把自己卡死的原因。

## 下载与使用

- 附件：`随影ShadeBar_v1.3.2.exe`（单文件，免安装）。
- 从 1.3.0 / 1.3.1 升级：直接替换 exe 即可，配置沿用 `%LOCALAPPDATA%\ShadeBar\config.json`。
- 验证方式：任务管理器 → 右键「Windows 资源管理器」→ 重新启动，几秒后托盘图标应自动回来。

## 环境与限制

- Windows 11 26H2（Build 26300.9711）真机验证；更早版本未承诺。
- 需要注入 explorer（元素级着色的唯一可行路径）。写错会让任务栏重启，不会损坏系统。
- 托盘字形图标可着色；微信、QQ 等程序自绘位图图标保持原样。
- 悬停高亮块尚未验证，未开放设置。

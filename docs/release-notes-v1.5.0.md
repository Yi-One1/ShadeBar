# 随影 ShadeBar v1.5.0

本次是功能版本（MINOR）：**配色与判定粒度解耦**，统一模式下四类内容也能各自配色；
同时修正预览端色语义、取色浮层越界与指示条状态切换延迟。

## 改进

- **配色与判定粒度解耦（S-47）**：判定粒度只决定明暗判断方式——「分区独立」三区各自判定，
  「全任务栏统一」三区取平均。四类内容（正常态指示条、选中态指示条、托盘字形、时间与日期）
  在两种粒度下都按 S-52 ~ S-59 各自取「背景偏暗 / 偏亮」两色，统一模式不再回落到
  S-14 / S-15。设置页两种模式都显示 4×2 色块矩阵。
- S-14 / S-15 从 UI 收起（配置值与编号保留，仅作兼容）；可见设置 30 → **28** 项。
- **亮 / 暗端预览语义修正**：亮端 = 浅色文字 → 深色任务栏，预览条与 Y 读数标签同步反向。

## 修复

- **时间与日期取色浮层右侧越界**：浮层 x 坐标夹紧在设置窗口内，任务栏最右一列色块可正常点选。
- **选中 → 正常切换后指示条滞留选中色约 2 s**：`OnElementStateChanged` 对 `RunningIndicator`
  不触发。载荷改为在 XAML UI 线程每 250 ms（空闲 1 s）只读 `ActualWidth` 探测状态变化，
  变化即置脏并置急，实测切换延迟降到 **0.14–0.48 s**。

## 兼容性与已知限制

- 已在 Windows 11 26H2 Build 26300.9711 实测；Windows 10 未验证。
- 单文件 exe，**无需 VC++ 运行库**；普通用户权限，全生命周期 **UAC = 0**。
- 载荷 DLL 已更新：升级后若颜色行为异常，请重启资源管理器（explorer）或重启电脑，
  让 explorer 加载新副本。
- 图片型托盘图标（第三方应用自绘位图）仍无法染色；多显示器仍只处理含任务栏的主屏。
